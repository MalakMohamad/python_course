# Python Course Practice

A repository for Python course notes, exercises, and practice code.

## Purpose

Organize learning exercises while strengthening Python programming fundamentals through hands-on practice.

## Learning Approach

- Review a concept.
- Practise it in a small script.
- Run the code and check the output.
- Refactor or add comments to make the logic easier to understand.

## Running Python Files

Use Python 3 to run a script from the repository:

```bash
python filename.py
```

Replace `filename.py` with the script you want to execute.
